# 英语48音标＋示例单词真人点读卡 V3

本版在 V2 基础上做了两项核心升级：

1. 复核并修正 48 个音标的中文近似提示与发音要点，避免把汉字当成精确发音。
2. 每张卡增加“示例单词真人发音”，与原“音标真人发音”分开播放。

## 音频来源

- 单独音标音频：`resetsix/english-ipa` 项目中的 48 个音标录音。
- 示例单词：Wikimedia Commons / Wiktionary 收录的真人录音；绝大多数为 UK/London/Southern England，少量组合音示例（train/cats/beds）使用 US 真人录音，并在卡片右侧标出 `US`。
- Wikimedia Commons 上不同文件采用各自许可；Shtooka 英国英语录音常见为 CC BY 3.0 US，其他文件请以各自文件说明页为准。

## 重要教学说明

- 中文提示仅用于记忆口型和听感，不是等价发音。
- `/tr dr ts dz/` 为国内 48 音标教材常单列的组合音，不等于独立单音位。
- `/ʊə/` 在现代英音中存在明显合流现象；本卡按传统教材保留。
- `/ɡ/` 使用真正 IPA 字符 `ɡ`，不是普通字母 `g`。

## 离线

点击“下载离线音频”后，页面会缓存音标和示例单词的全部音频。iPhone Safari 可再“添加到主屏幕”。
